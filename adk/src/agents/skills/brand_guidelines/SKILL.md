# Enterprise Brand Guidelines

Use these guidelines when generating or transforming slides to adhere to professional presentation styling.

## Core Palette

When designing presentation slides, use these primary brand color accents:

- **Primary Blue**: `#4285F4`
- **Accent Red**: `#EA4335`
- **Highlight Yellow**: `#FBBC05`
- **Secondary Green**: `#34A853`

## Typography

- **Headings / Title text**: Use clean, modern geometric sans-serif fonts (e.g., Arial, Inter, Helvetica).
- **Body text / Descriptions**: Use clear, highly legible sans-serif fonts (e.g., Roboto, Open Sans).

## Layout & Backgrounds

- **Backgrounds**: Prefer clean white (`#FFFFFF`) or light gray (`#F8F9FA`) backgrounds to ensure contrast and readability.
- **Margins & Grids**: Use generous padding and clear alignment. Do not crowd elements or overlap text.
- **Aesthetic**: Follow a minimalist, modern design philosophy.
